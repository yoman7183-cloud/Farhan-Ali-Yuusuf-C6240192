# Farhan-Ali-Yuusuf-C6240192

Sharaxaad

Barnaamijkan wuxuu ku saabsan yahay xisaabinta mushaharka shaqaalaha shirkad ku taalla Muqdisho. Wuxuu ka kooban yahay saddex nooc oo shaqaale ah: kuwa shaqeeya waqti-buuxa, kuwa shaqeeya waqti-dhiman iyo maamulayaasha.

Shaqaale kasta mushaharkiisa si gaar ah ayaa loo xisaabinayaa. Qaar waxaa mushaharkooda lagu daraa gunno, halka kuwa waqti-dhiman lagu xisaabiyo saacadaha ay shaqeeyaan iyo lacagta saacaddii. Barnaamijku wuxuu soo bandhigayaa magaca shaqaalaha, qaybta uu ka shaqeeyo iyo mushaharka uu qaadanayo bishii.





Sharaxaad

Barnaamijkan wuxuu ku saabsan yahay xisaabinta lacagta adeegyada caafimaadka ee isbitaal. Wuxuu ka kooban yahay saddex adeeg: la-tashiga dhakhtarka, baaritaanka shaybaarka iyo Ultrasound.

Adeeg kasta wuxuu leeyahay lacag u gaar ah, waxaana lagu daraa kharashka dheeraadka ah ee adeeggaas. Barnaamijku wuxuu soo bandhigayaa lacagta laga qaadayo adeeg kasta, kadibna wuxuu isku daraa dhammaan kharashaadka si loo helo wadarta lacagta uu bukaanku bixinayo.
